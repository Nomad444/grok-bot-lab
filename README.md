# Grok Bot Lab 🤖

Small bots that do one job each. Import one, say hi, start using it.
No code, no setup files. Each bot asks a few questions when you first say hi.

## How to use
1. Open an import link.
2. Say hi. The bot asks a few setup questions (language, time zone).
3. Check its routines: new ones can start paused.

## Tips
- One routine, one job, one "when to stay quiet" line.
- Check the time zone, not only the hour.
